# CSharpCodeDetective     
CSharp variant of CodeDetective    
The original was written in Qt5 and was cross platform (Windows and Linux)     

## Setting up tags      
Copy ctags.exe to the project folder.   
Build ctags from CodeDetective Menu.    
Search for Identifiers using find tags.
